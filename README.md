## Inspiration

Colonia is a eurodance group from Croatia that stood out on the local and European eurodance scene during the late '90s and early 2000s. For the design, I chose a dark crimson/red color palette, which represents the eurodance/2000s vibe. I used shadows and gradients a lot throughout this project, but I didn't use things such as border-radius for few reasons, first of which is it's more common for modern websites, and I tend to keep that 2000s style on this site. Second reason is because any design closely related to AI seems completely soulless to me.  Other than that, Montserrat font was used with bright biege color for perfect contrast which differs from background of the page. I wanted to use font which looks like a man could write with it, but not like handwritting font.
